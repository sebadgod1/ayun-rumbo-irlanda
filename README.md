# Ayün — Rumbo a Irlanda 🌸🇮🇪

PWA personal, mobile-first, pensada como una compañera cálida y firme para construir constancia rumbo a Irlanda.

## Principios
- Simple de usar: la pantalla principal se entiende en segundos.
- Rosa palo como identidad visual, con navy/prune para contraste.
- Seis esenciales diarios, movimiento semanal, alimentación y ánimo.
- Alimentación y ánimo no entregan XP.
- Vitaminas/medicamentos: solo adherencia a una pauta ya existente. La app no recomienda dosis, horarios ni cambios.
- Datos locales, respaldo JSON/CSV y funcionamiento offline.

## Objetivos semanales
- Bicicleta: 4 sesiones.
- Fuerza/pesas: 3 sesiones.

## Desarrollo
No usa dependencias ni build step. Basta servir la carpeta por HTTPS (GitHub Pages funciona perfecto).
